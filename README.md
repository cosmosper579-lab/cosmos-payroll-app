# โปรแกรมจ่ายเงินคนงาน — ไฟล์อัปเดต

โปรแกรมที่ติดตั้งในคอม (Mac / Windows) จะมาดึงเวอร์ชันใหม่จากโฟลเดอร์ `update/` เองทุกครั้งที่เปิด และทุก 30 นาที

- `update/index.html` — ตัวระบบเวอร์ชันล่าสุด
- `update/version.json` — เลขเวอร์ชัน + sha256 ของไฟล์ (ไฟล์ไม่ตรงจะไม่ถูกใช้)

ที่นี่มีแค่ตัวโปรแกรม ไม่มีข้อมูลคนงาน (ข้อมูลอยู่ในเครื่องและ Firebase)

## แอปมือถือ (Android)

เปิด https://cosmosper579-lab.github.io/cosmos-payroll-app/ ใน Chrome บนมือถือ แล้วกด "📲 ติดตั้งแอปลงมือถือ" (หรือเมนู ⋮ → ติดตั้งแอป)

- `manifest.webmanifest`, `icons/` — ชื่อและไอคอนแอป
- `sw.js` — เก็บตัวโปรแกรมไว้ในเครื่อง ใช้ได้ตอนไม่มีเน็ต และดึงรุ่นใหม่จาก `update/index.html` ทุกครั้งที่มีเน็ต
